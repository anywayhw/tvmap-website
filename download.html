安装说明

  1. 下载 APK 文件，通过 U 盘、网盘或局域网文件管理器传输到电视。
  2. 在电视上点击 APK 文件开始安装，如提示「未知来源」，请在设置中允许安装未知来源应用。
  3. 安装完成后打开应用，按遥控器「菜单键」进入设置，填入高德地图 API Key。
  4. 回到地图页面即可开始使用，详细步骤见帮助页。

无需特殊权限，应用不采集任何数据，可放心使用。
