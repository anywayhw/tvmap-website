使用帮助

1遥控器操作方法

TVMap 的全部功能都可以通过电视遥控器完成，无需鼠标和键盘。

功能按键
移动地图方向键 上下左右
切换缩放模式确认键（开启后 上 放大、下 缩小）
打开设置菜单键
退出应用返回键（需二次确认，防止误退）

2设置说明

打开应用后按遥控器「菜单键」进入设置，可配置以下项目：

  • 地图类型：普通地图 / 卫星地图 / 夜景地图（左右键切换）
  • 实时路况：开关，控制路况图层显示（左右键切换）
  • 显示文字：开关，控制 POI 文字标注显示
  • API Key：高德地图开发者 Key（获取方法见下方教程）

3高德地图 API Key 申请方法

TVMap 使用高德地图 Android SDK，需要填入你免费申请的高德开放平台 Key 才能加载地图。申请步骤：

  1. 打开高德开放平台，注册并登录开发者账号。
  2. 进入「应用管理」→「我的应用」，点击「创建新应用」，应用名称填写 TVMap。
  3. 在应用下点击「添加 Key」，Key 名称填写 TVMap，服务平台选择「Android 平台」。
  4. 配置 Android 安全码：
    • 发布版安全码（SHA1）与调试版安全码（SHA1）：填写相同的值（具体数值可在应用内设置页的教程中查看）。
    • PackageName（包名）：填写 com.tvmap.app。
  5. 提交后复制生成的 Key，在电视上打开 设置 → API Key，输入并保存。

应用设置页内附有图文教程，可对照操作。申请 Key 完全免费。

通用电视遥控器 · 方向键 + 确认 / 菜单 / 返回

小贴士 缩放模式下按「上」放大地图、按「下」缩小地图，再按一次确认键即可回到移动模式。多练习几次，操作会非常顺手。
